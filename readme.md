# OutfitIQ - Fashion Price Predictor 💡

**OutfitIQ** is a Python-based deep learning project that predicts the price of fashion items using a PyTorch neural network. It includes a **Streamlit web interface** for interactive, real-time predictions.

---

## Features

- Predict prices for fashion items like Hoodies, Jeans, Jackets, Sneakers, etc.  
- Input features: **Item Name, Category, Color, Size, Gender, Season, Material**.  
- Uses a **PyTorch regression model** for accurate predictions.  
- Interactive **Streamlit app** for live price prediction.
